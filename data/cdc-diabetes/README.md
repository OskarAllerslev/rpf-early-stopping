# CDC Diabetes Health Indicators
- Source: UCI ML Repository, dataset 891 — https://archive.ics.uci.edu/dataset/891
- Origin: CDC Behavioral Risk Factor Surveillance System (BRFSS) survey
- Citation: CDC Diabetes Health Indicators [Dataset] (2017). UCI Machine Learning Repository. https://doi.org/10.24432/C53919
- Size: 253,680 people, 21 features, no missing values
- Response: `Diabetes_binary` (0 = no diabetes, 1 = prediabetes or diabetes)
- Features: mostly binary (HighBP, HighChol, Smoker, ...), plus BMI, age group, general/mental/physical health, income and education
- Preprocessing by the source: age is bucketed
- Downloaded: 2026-10-20
