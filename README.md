# Early stopping for Random Planted Forests

Research project: data-driven early stopping rules for random planted forests
(Hiabu, Mammen & Meyer, arXiv:2012.14563), building on the early-stopping theory for
regression trees of Miftachov & Reiß (arXiv:2502.04709).

Contributors: Oskar Allerslev, Markus Baltzer. AI-assisted research (see AGENTS.md once added).

## Core references
- Hiabu, Mammen, Meyer. *Random Planted Forest: A Directly Interpretable Tree Ensemble.* https://arxiv.org/abs/2012.14563
- Miftachov, Reiß. *Early Stopping for Regression Trees.* https://arxiv.org/abs/2502.04709
